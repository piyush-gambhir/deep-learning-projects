# Deep Learning Projects

A collection of deep-learning project notebooks across computer vision, NLP, and predictive modelling.

## Projects

- **Advanced Churn Modeling** — customer-churn prediction with neural networks
- **Amazon Alexa Review Sentiment Analysis** — sentiment classification on Alexa reviews
- **Chatbot With Deep Learning** — sequence-to-sequence conversational model
- **Earthquake Prediction Model** — time-series prediction on seismic data
- **Face Mask Detection** — CNN classifier for masked vs unmasked faces
- **Image Classification** — generic image-classification baseline
- **Image Colorization using Deep Learning** — grayscale → colour with autoencoders
- **Landmark Detection Model** — landmark recognition on tourist imagery
- **Movies Title Prediction** — title generation from synopses
- **Pneumonia Detection** — chest X-ray classification

## Stack

Python, TensorFlow / Keras, PyTorch, NumPy, pandas, matplotlib. Each project lives in its own directory with a notebook, model artefacts, and a brief readme where applicable.

## Running

```bash
cd "Face Mask Detection"
pip install -r requirements.txt   # if present
jupyter notebook
```
